# List registered SimtablR engines

List registered SimtablR engines

## Usage

``` r
list_engines()
```

## Value

A character vector of registered engine names.

## See also

[`register_engine()`](https://MatheusTG-14.github.io/SimtablR/reference/register_engine.md)

## Examples

``` r
list_engines()
#> [1] "accuracy"    "bivariate"   "cox"         "descriptive" "e_value"    
#> [6] "glm"         "roc"        
```
