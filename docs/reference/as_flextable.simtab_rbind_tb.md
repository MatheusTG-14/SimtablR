# Convert simtab_rbind_tb Object to Flextable

Convert simtab_rbind_tb Object to Flextable

## Usage

``` r
as_flextable.simtab_rbind_tb(x, footnotes = NULL, ...)
```

## Arguments

- x:

  A `simtab_rbind_tb` object.

- footnotes:

  Optional character vector of footer lines appended to the table.

- ...:

  Additional arguments passed to
  [`flextable::flextable()`](https://davidgohel.github.io/flextable/reference/flextable.html).

## Value

A `flextable` object.

## Examples

``` r
if (requireNamespace("flextable", quietly = TRUE)) {
  t1 <- tb(epitabl, sex, diabetes)
  t2 <- tb(epitabl, hypertension, diabetes)
  as_flextable.simtab_rbind_tb(rbind(t1, t2))
}
```
