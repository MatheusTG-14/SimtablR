# SimtablR: Easy Publication-Ready Tables and Regression Analysis

Streamlines the creation of descriptive frequency tables ('Table 1'),
diagnostic test accuracy evaluations (sensitivity, specificity,
predictive values), and multi-outcome regression summaries. Features a
grammar for publication-ready epidemiological tables built on
design-aware effect measures, prevalence and odds ratio calculations,
and seamless integration with 'flextable' for exporting results to
'Microsoft Word' and 'PowerPoint'.
